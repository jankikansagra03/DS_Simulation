📚 Core Stack Operations & Algorithms

A Stack is a linear data structure operating strictly on the LIFO (Last In, First Out) principle. The index variable TOP points to the topmost valid element. When initialized, TOP = -1 (empty).

1. PUSH(S, TOP, N, X) Insert

Inserts a new element X onto the top of stack S of max size N. Verifies TOP ≥ N - 1 to prevent Stack Overflow.

[Check for Stack Overflow]
1. If TOP ≥ N - 1
       Then write "STACK OVERFLOW" and Return
[Increment TOP Pointer]
2. TOP ← TOP + 1
[Insert Element into Top Slot]
3. S[TOP] ← X
[Finished]
4. Return

2. POP(S, TOP) Delete

Removes and returns the topmost element X. Checks if the stack is empty (TOP = -1) to prevent Stack Underflow.

[Check for Stack Underflow]
1. If TOP = -1
       Then write "STACK UNDERFLOW" and Return
[Retrieve Element]
2. X ← S[TOP]
[Decrement TOP Pointer]
3. TOP ← TOP - 1
[Finished]
4. Return X

3. PEEP(S, TOP, I) Inspect

Views an element at depth I from top without removing it (I = 1 is top, I = 2 is one below). Formula: TOP - I + 1.

[Check for Invalid Index]
1. If TOP - I + 1 < 0
       Then write "STACK UNDERFLOW / INVALID INDEX"
       Return
[Access Element at Depth I]
2. X ← S[TOP - I + 1]
[Finished]
3. Return X

4. CHANGE(S, TOP, I, VALUE) Modify

Updates an existing element at depth I from the top with a new VALUE without modifying the surrounding elements.

[Check for Invalid Index]
1. If TOP - I + 1 < 0
       Then write "STACK UNDERFLOW / INVALID INDEX"
       Return
[Update Element at Depth I]
2. S[TOP - I + 1] ← VALUE
[Finished]
3. Return

5. PEEK(S, TOP) View Top

Quickly inspects the current topmost element S[TOP] in $O(1)$ time without popping it.

[Check for Underflow]
1. If TOP = -1
       Then write "STACK EMPTY" and Return
[Access Top Element]
2. Return S[TOP]

6. TWO_STACKS(S, N, TOP1, TOP2) Dual Array

Stack 1 grows from index $0 \rightarrow N-1$. Stack 2 grows backwards from $N-1 \rightarrow 0$. Space is optimal; collision occurs only when TOP1 + 1 == TOP2.

[Collision / Overflow Condition]
If TOP1 + 1 == TOP2
    Then write "STACK OVERFLOW (COLLISION)"
[Push Stack 1]: TOP1 ← TOP1 + 1; S[TOP1] ← X
[Push Stack 2]: TOP2 ← TOP2 - 1; S[TOP2] ← X

🧮 Expressions & REVPOL Conversion Manual

Arithmetic expressions can be formatted into three equivalent notations. Compilers convert human-friendly Infix into Postfix (Reverse Polish) because Postfix eliminates parentheses and can be evaluated linearly in $O(N)$ with a Stack.

Sr. No. Infix Notation Prefix Notation (Polish) Postfix Notation (Reverse Polish)
1a + b+ a ba b +
2(a + b) * c* + a b ca b + c *
3a * (b + c)* a + b ca b c + *
4a / b + c / d+ / a b / c da b / c d / +
5(a + b) * (c + d)* + a b + c da b + c d + *
6((a + b) * c) - d- * + a b c da b + c * d -

Table: Precedence & Rank Used in REVPOL Algorithm

Symbol F (Incoming Precedence) G (In-Stack Precedence) R (Rank Contribution) Function / Role
+ , - 1 2 -1 Addition & Subtraction (Left-associative)
* , / 3 4 -1 Multiplication & Division (Higher precedence)
^ (Power) 6 5 -1 Exponentiation (Right-associative: F > G)
Operand 7 8 +1 Identifiers & Constants (Appended directly to output)
( Left Paren 9 0 0 High incoming to enter stack, low in-stack so nothing pops it
) Right Paren 0 — 0 Pops everything until matching '(' is reached
